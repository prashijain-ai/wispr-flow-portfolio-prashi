# Wispr Flow India Growth Lab 🇮🇳🎙️

> Built for the Wispr Flow x Emergent Hiring Challenge (India Growth Team).

A live, interactive growth playbook and portfolio built entirely by voice using **Wispr Flow** and **Emergent** during the November 2026 challenge window.

## 🚀 What's Inside
- **Hero & Voice Note:** A custom 24-second audio intro demonstrating real voice-to-text integration.
- **IIT Madras Proof Strip:** Highlighting ML hackathons, Kaggle rankings, and full-stack architecture.
- **The "Flow Story" & Hinglish Test:** Real-world comparison testing (e.g., *Hacktoberfest* vs. Google Voice search *October Fest*) and multi-lingual prompt testing.
- **Interactive Growth Strategies:** 3 actionable expansion playbooks for India (Hinglish Reels, Campus Squads, Builder Communities) featuring explicit **Kill/Scale thresholds**.
- **Live Experiment Panel & Creator Target Board:** Structured hypotheses and target creator tiers (Macro to Micro) tailored for the Indian creator economy.

- **AI Builder:** Emergent
- **Voice Engine:** Wispr Flow (Mac / iOS)
